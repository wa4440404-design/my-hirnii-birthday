- index.html       Website code
- hirnii-1.jpg     First photo you supplied
- hirnii-2.jpg     Second photo you supplied

MUSIC:
Add a romantic MP3 file in this same folder and name it exactly:
music.mp3

The music starts after the visitor taps "Open Your Surprise".
The volume slider is set to 85% initially and can be adjusted.

PUBLISH ON GITHUB:
1. Create a new public GitHub repository.
2. Upload all these files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site and copy the link.

Keep the filenames unchanged, or update the image/audio filenames in index.html.
